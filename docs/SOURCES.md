# Historical game and artwork reference sources

## Player-supplied PDF: *Fall from Heaven II 0.30 Manual*

The project has a user-supplied copy of the 55-page *Fall from Heaven II 0.30 Manual* (Fredrik Henriksson, created January 2008). It contains civilization lore, distinctive mechanics, the original small illustrations of unique units and buildings, portraits of heroes and leaders, and broad visual references.

**Do not assume the original manual reflects the later ExtraModMod balance.** For playable stats, promotion sets and prerequisites, the authoritative reference is the matching ExtraModMod XML/Python/DLL implementation at [bewlay/extramodmod](https://github.com/bewlay/extramodmod). Capture any discrepancies as explicit version differences.

The initial Amurite Firebow/Govannon sprites are newly authored concept art inspired by the user-supplied in-game icon/hero illustrations; **do not directly extract and distribute the manual's images** without resolving their distribution rights.

## Gameplay sources

- [ExtraModMod source repository](https://github.com/bewlay/extramodmod): `XML/Civilizations/CIV4CivilizationInfos.xml`, `XML/Units/CIV4UnitInfos.xml`, `XML/Buildings/CIV4BuildingInfos.xml`, `XML/Units/CIV4PromotionInfos.xml`, `CvGameCoreDLL/`, `python/`.
- [Official Unciv ruleset modding docs](https://github.com/yairm210/Unciv/tree/master/docs/Modders): JSON field definitions, `uniques`, leader portrait names, tile sets and atlas conventions.
- User-approved new Valledia portrait and Firebow/Govannon sprite concept references from this project's discussion.

This repository is a **base-ruleset mod**; using a PDF/manual for reference is not permission to change the Unciv engine or repackage proprietary FFH2 source art.
