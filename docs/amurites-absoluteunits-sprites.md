# Amurites Absolute Units sprite pack

10 original-user-screenshot-derived 95×81 transparent indexed PNGs, 22-color palette, preserved equipment and silhouettes. Snow backgrounds masked using GrabCut, artwork resized to native Absolute Units bounds and quantized for pixel style.

- Shared unit overrides (Amurites only): Adept, Archer, Archmage, Beastmaster, Champion, Chariot and Crossbowman, stored as `<Unit>-Amurites`.
- Amurites-only units already in ruleset: Chanter and Firebow, named exactly as their unit definitions.
- Govannon art and atlas registered in advance. **Govannon currently has no unit definition in Units.json**; his sprite alone does not introduce a playable hero or substitute made-up hero mechanics.
- Entries registered in the new `amuritesunits.atlas` multi-page texture atlas and `Atlases.json`.
- Existing Goblin, Warrior sprites, mechanics, and freely selectable unitsets unchanged.

Source reference: 10 EMM screenshots supplied in this conversation: adept.png, archer.png, archmage.png, beastmaster.png, champion.png, chanter.png, chariot.png, crossbowman.png, firebow.png, govannon.png.

Game display is not independently tested. Please review directly at native unit scale in Absolute Units.
