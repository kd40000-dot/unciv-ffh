# Fall from Heaven — Unciv

A **standalone Unciv base ruleset prototype**, with **ExtraModMod Continued** as the authoritative target.

## First early-game slice

Includes **19 normally playable EMM civilizations**, the EMM-derived technology tree, **102 units** and **69 buildings**, plus terrain, resources and improvements. This is **not yet a complete or Android-playtested port**.

Install with Unciv → Mods → Download mod from URL:

`https://github.com/kd40000-dot/unciv-ffh`

See [full civilization roster](docs/civilizations.md), [leader traits and palaces](docs/leader-palace-fidelity.md), [economic/raiding traits](docs/economic-traits.md), [source starting units](docs/starting-units.md), [promotions, upgrades and resources](docs/promotions-upgrades-resources.md), [unit and building source conversion](docs/units-and-buildings.md), [complete technology tree](docs/technology-tree.md), [test steps and limitations](docs/first-playable-slice.md), [development plan](docs/implementation-plan.md), and [compatibility ledger](docs/compatibility.md).
