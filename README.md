# Fall from Heaven — Unciv

A **standalone Unciv base ruleset prototype**, with **ExtraModMod Continued** as the authoritative target.

## First early-game slice

Includes **Amurites, Bannor, Clan of Embers and Ljosalfar**, the EMM-derived technology tree, **47 source-derived units** and **40 buildings**, plus terrain, resources and improvements. This is **not yet a complete or Android-playtested port**.

Install with Unciv → Mods → Download mod from URL:

`https://github.com/kd40000-dot/unciv-ffh`

See [unit and building source conversion](docs/units-and-buildings.md), [complete technology tree](docs/technology-tree.md), [test steps and limitations](docs/first-playable-slice.md), [development plan](docs/implementation-plan.md), and [compatibility ledger](docs/compatibility.md).

Pinned authoritative game source: [EMM Continued](https://github.com/bewlay/extramodmod/tree/60b0ec3740083162aaab7bf8491761a54a65a610).

Old pre-reset implementation remains archived in `archive/pre-reset-2026-10-21` and was **not reused**.
